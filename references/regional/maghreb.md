# Market: Maghreb — Morocco, Algeria, Tunisia

One file, three *non-interchangeable* markets (same warning as the
southeast-asia file): read the country section, never the file average.
Verified against local sources 2026-08 (Jobsquare, Rekrute, Stagiaires.ma;
Emploitic, Africarrières; Tanitjobs, Keejob). Where a point could not be
confirmed by a local primary source it is labelled LOW confidence.

Paper: a4 (all three).

## Shared baseline (all three countries)

- **CV language: French is the private-sector norm** (banking, audit,
  multinationals); Arabic mainly for the public sector; English rising fast
  in tech/finance/multinationals and often required bilingually in
  international finance hubs. The posting's language dictates the CV's.
- **Photo: still culturally expected** in local practice (formal,
  front-facing, neutral background — DACH mechanics), though not legally
  required and slowly declining in multinationals. Tell the user the local
  custom; the candidate decides.
- French CV mechanics apply (see `france.md`): espace insécable before `:`,
  typographic apostrophes, months lowercase, noun-phrase or past-participle
  bullets. Dates: month/year.
- A **« titre de CV »** (a targeted role headline under the name) is expected
  and worth retailoring per application (verified for Morocco; LOW for the
  other two, but harmless everywhere).
- Job boards: Morocco — Rekrute, Emploi.ma, Anapec (public); Algeria —
  Emploitic (dominant), Ouedkniss, Emploi Partner; Tunisia — Tanitjobs
  (dominant), Keejob, ANETI (state sector). LinkedIn for cadres everywhere.
- Regulated titles: expertise comptable is ordre-regulated in all three
  (OEC Maroc, OECA Algérie, OECT Tunisie) — LOW confidence on the exact
  scope, check the ordre before writing any regulated-sounding title
  (universal rule in `regional.md`).

## Where the three diverge (the file average is wrong)

| | Morocco | Algeria | Tunisia |
|---|---|---|---|
| Length | 1 p. junior (<5 yrs), 2 p. max senior | **2-3 p. normal** — detailed CVs expected | 1 p. clearly preferred; 2 p. only very senior |
| Personal data | Birth date/nationality still common but declining; marital status on its way out — omit by default and say so | **Maximalist**: birth date+place, marital status, children, wilaya, nationality still customary; omitting can hurt a file | Modern guides explicitly advise dropping age/sex/marital status — omit |
| Country-specific field | **Note du bac if >14/20** is worth listing (rare elsewhere) | **Service national** status is a real field, unique to Algeria | Language levels phrased « notions / courant / bilingue », never « lu, parlé, écrit » |

## Country notes

**Morocco.** 1 page junior. Photo quasi-expected. Date format mois/année.
Nationality/birth date still seen but declining — omit by default, flag the
custom to the user. Mention the bac grade when above 14/20. Sage dominates
PME accounting stacks, SAP the large groups/Big Four; audit postings
increasingly name data tools (Power Query, ACL, IDEA) beyond advanced Excel.

**Algeria.** The outlier: longer CVs (2-3 pages) and the fullest personal-data
custom of any market in this skill — closer to pre-2010 French practice.
Anti-discrimination minimalism has NOT landed here; the universal
omit-by-default rule still applies, but warn the user that local recruiters
(per Emploitic guidance) may expect birth data, marital status and service
national, and let the candidate decide. Public sector wants Arabic.

**Tunisia.** Closest of the three to modern French practice: 1 page, minimal
personal data, photo still common in local models. FR/EN bilingual profiles
sought in banking/multinationals.
