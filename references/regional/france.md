# Market: France

Paper: a4. Length: 1 page strongly preferred, all seniority levels.

- Photo: declining fast — many recruiters now advise omitting; anonymous-CV
  practice is growing (public sector, large groups). Age/marital: not
  required; omit by default.
- Bullet style: noun phrases (« Conception de… ») or past participle
  (« Développé… ») — not the Québec infinitive.
- French mechanics: espace insécable before `:` (`~:` in Typst),
  « guillemets », typographic apostrophes, months lowercase.
- Hobbies (« centres d'intérêt ») still read as a personality signal — a
  short line is normal, unlike US/UK practice.
- Protected titles: many state-regulated professions (santé, droit,
  expertise comptable…). Nursing, for example, requires the Diplôme d'État —
  using the title is legitimate only with the registration, which also makes
  it a credential worth showing. Check the profession's ordre before writing
  any regulated title.
