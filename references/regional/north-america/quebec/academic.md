# Academic: Québec

Loaded on demand when the document is an academic CV for a Québec target. Generic genre rules: [`references/fields/academic.md`](../../../fields/academic.md). *(LOW, unsourced for the section structure, supported by the specimen the field pack was built from; the agency facts below carry S ids.)* Federal agencies and Canada-wide rules: [`../canada/academic.md`](../canada/academic.md).

- Bilingual reality: a French CV is normal within the Québec network; English for a search outside Québec. The target language governs the whole deliverable.

## FRQ formats
As of September 2026: the technical bridge between FRQnet and the Canadian Common CV was disabled on December 19, 2025; no FRQ program requires the CCV in 2026. The current reference format is the CV-FRQ, a descriptive CV filled directly into the "CV-FRQ" section of the FRQnet application portal (FRQ, « Nouvelle étape dans le projet d’implantation du CV-FRQ : fin de la passerelle vers le CVC », consulted 2026-11-07, S34; FRQ, « CV-FRQ », consulted 2026-11-07, S33).
